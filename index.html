DEMO
A busca compara apenas imagens presentes no índice local. A porcentagem indica semelhança visual aproximada, não identidade de uma pessoa.
PRIVACIDADE

Feito para ser simples.

A imagem escolhida é enviada à API configurada para comparação com o índice de imagens. Evite enviar fotos sensíveis.
